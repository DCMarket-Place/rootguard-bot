# Privacy Policy for RootGuard Bot

**Last Updated:** September 24, 2026

RootGuard ("we", "our", or "the bot") is committed to protecting the privacy of community members and server administrators who interact with the RootGuard application on the Root platform (`rootapp.com`).

---

## 1. Information We Collect

RootGuard processes only the minimum data strictly necessary to provide management, moderation, leveling, and security features:

- **User Identifiers:** Unique Root User GUIDs (`userId`) are processed to track warnings, moderator actions, and XP level progression.
- **Community Identifiers:** Root Community GUIDs (`communityId`) and Channel GUIDs (`channelId`) are stored to associate server settings (welcome channels, logging channels, autoroles).
- **Message Content:** Message text is analyzed transiently in real-time by the AutoMod engine (to detect spam, mass mentions, and harmful invite links) and for command invocation (`/ban`, `/warn`, `/rank`).
- **Audit Logs:** Records of moderation actions (kick, ban, warning reasons, and timestamps) are maintained to preserve community accountability.

---

## 2. How Information is Used

The data collected is used solely for:
1. Executing server moderation and automated protection against raid attacks and spam.
2. Maintaining user experience features such as activity XP leveling, rank cards, and server leaderboards.
3. Automatically greeting new members and assigning default community roles.
4. Providing audit trails for server administrators.

We **do not** sell, rent, monetize, or share user data with third-party advertisers or external services.

---

## 3. Data Storage and Security

All bot settings and infraction logs are stored securely and encrypted in transit. Data is retained only for as long as necessary to provide service to the community. Community administrators may request data clearance at any time using in-app commands (`/clear`).

---

## 4. Contact Information

If you have questions, inquiries, or data removal requests regarding RootGuard, please reach out via our community developers channel on RootApp or submit an inquiry through our official repository.
